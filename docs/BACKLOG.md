## Работы студентов

- [x] **Смена автора работы.** Выбор другого студента того же курса, проверка профиля и актуального назначения, подтверждение новой версии. История хранит прежнего и нового автора, номера сдач, дату и преподавателя. Прежние копии для ИИ помечаются недействительными; новая копия готовится отдельно.

## Студенты

- [x] **Редактирование студента.** Имя и учебный номер изменяются в общей карточке профиля с проверкой уникальности непустого номера. Исключение из группы запрещено при наличии текущих работ: сначала их нужно переназначить или удалить. Подготовленные копии не переписываются.

## Копия для ИИ и ввод текста

- [x] **Имя с диакритикой и имя из файла.** Magi/Mägi и другие варианты с диакритикой сопоставляются. Дополнительные части имени извлекаются из CamelCase и подчёркиваний в имени файла. При нуле замен в работе показывается предупреждение.
- [x] **Регистр в коде.** Замена частей имени в code учитывает регистр: Max не заменяет max(). В markdown поиск по-прежнему без учёта регистра.
- [x] **Обрезание текста.** У полей с maxLength есть счётчик. При превышающей лимит вставке показывается предупреждение; учитывается длина выделения, которое заменяет вставка.
