# Состояние реализации

## Этапы 1 и 2 — реализовано

React и JavaScript, Node.js, SQLite, Electron. Локальные профили, курсы, фильтры, студенты, правила, задания, критерии и независимое копирование курса. Данные архивного макета не смешиваются с рабочей базой.

Карточки студентов с цветом и инициалами. Загрузка одного или нескольких ноутбуков .ipynb из задания или карточки. Предел — 5 МБ на файл. Автор назначается явно; файлы можно сохранить без автора и распределить позже. Повторная сдача требует подтверждения и создаёт новую версию.

Неизменённые оригиналы хранятся на диске с SHA-256. Просмотр показывает текст и код без исполнения. Незавершённый импорт восстанавливается после перезапуска или помечается ошибкой. Подготовленная копия использует версию задания, зафиксированную при импорте.

Копия для ИИ создаётся только локально, без метаданных, выводов, вложений и raw-ячеек. Известные имя и номер, адреса почты и некоторые телефоны заменяются маркерами. Преподаватель редактирует JSON и отмечает просмотр. Это не гарантия анонимности. Правки копии хранятся отдельными редакциями. Отправки в ИИ нет.
